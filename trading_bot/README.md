# 자동매매 봇

**직접 트레이딩 보류 중.** 현재 코드는 봇 시작과 시장가·지정가 매수·매도, 주문 취소를 차단한다. 보유 현황과 투자 의견은 [분야별 에이전트](../agents/README.md)에서 관리한다.

## 기존 전략 구성

1. **데이터 기반 시그널 생성**
   - 기존 RiskPredictor의 고변동성 확률 활용
   - 특성 중요도 기반 가중치 적용
   - 동적 변수 분석

2. **김치 프리미엄 필터**
   - 역프 또는 낮은 김프일 때만 매수 허용
   - 역프 상태일 때 포지션 크기 2배

3. **리스크 관리**
   - 손절매/익절 자동 실행
   - 최대 포지션 비율 제한

4. **텔레그램 알림**
   - 매수/매도 체결 알림
   - 에러 알림

## 설치 방법

```bash
# 1. 설치 스크립트 실행
python install_trading_bot.py

# 2. Streamlit 앱 실행
streamlit run app/main.py
```

## 사용 방법

Streamlit의 자동매매 메뉴는 보류 상태를 표시한다. 로컬 보유 코인의 검토 목록은 `python3 -m private_accounts portfolio-review crypto`로 확인한다.

## 기존 시스템과의 관계

- **독립적인 모듈**: 기존 데이터 수집 DB와 분석 서비스에 영향 없음
- **읽기 전용**: 기존 `data/project.db`는 읽기만 하고 수정하지 않음
- **별도 설정**: `trading_bot/config/`에 별도 설정 파일 사용
