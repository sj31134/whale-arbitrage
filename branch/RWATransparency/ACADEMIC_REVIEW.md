## Part 1: 팩트체크 (방법론적 검증)

### ✅ 순환 논리 제거 확인

#### 검증 1: 가격/거래량 데이터 출처
```
파일: data/raw/historical_prices.csv
출처: CoinGecko API (실제 시장 데이터)
샘플 확인:
- ONDO: 2025-08-13 가격 $1.0596, 거래량 $219M, 시총 $3.35B
- BUIDL: 가격 $1.0 (페그), 거래량 $0 (기관 토큰)
```
**결론**: ✅ 실제 시장 데이터 확인됨

#### 검증 2: TDT 점수 출처
```
파일: data/raw/offchain_disclosure.csv
출처: RWA_DISCLOSURE_SOURCES 딕셔너리 (연구자 직접 조사)
계산 방식:
- latency_score: 감사 빈도 기준 (monthly=90, quarterly=60, etc.)
- completeness_score: 8개 필수 필드 중 공개 비율
- consistency_score: 보관기관 명시 여부 기준
```
**결론**: ✅ 가격 데이터와 독립적으로 계산됨

#### 검증 3: 순환 논리 부재 확인
```
이전 (시뮬레이션):
  base_vol = 0.03 * (1 - tdt / 200)  # TDT가 Y를 직접 결정

현재 (실제 데이터):
  Y (volatility_7d) = CoinGecko 실제 가격에서 계산
  X (tdt_score) = 공시 정보에서 계산
  → 두 변수가 독립적
```
**결론**: ✅ 순환 논리 제거됨

### ⚠️ 남아있는 방법론적 한계

#### 한계 1: TDT 점수의 주관성 (Subjectivity)
```python
# collect_disclosure_data.py Line 21-93
RWA_DISCLOSURE_SOURCES = {
    'ondo-finance': {
        'known_fields': ['aum', 'nav_frequency', 'custodian', ...],  # 연구자 주관
        'auditor': 'Based on published attestations'  # 정확한 빈도 모름
    }
}
```
**문제점**:
- `known_fields`는 연구자가 웹사이트를 보고 **수동으로 판단**
- `auditor` 정보의 정확성 검증이 어려움
- 재현성(Replicability) 우려

**권장 조치**:
- 각 토큰별 공시 출처 URL과 수집 날짜를 명시
- 가능하면 2명 이상의 독립적 코딩으로 신뢰도 확보

#### 한계 2: 정보 없는 토큰의 TDT 처리
```
offchain_disclosure.csv에서:
LUSD, GUSD, TUSD, BUSD, EURC 등 → latency=0, completeness=0, consistency=50
→ TDT = (0 + 0 + 50) / 3 = 16.67
```
**문제점**:
- 22개 토큰 중 13개(59%)가 정보 부족으로 TDT=16.67
- 이분화된 분포: 고TDT(62-87) vs 저TDT(16.67)
- 중간값이 없어 선형 관계 추정에 불리

**권장 조치**:
- 정보 없는 토큰은 분석에서 제외하거나 별도 그룹으로 처리
- 또는 "정보 부족 더미 변수" 추가

#### 한계 3: 시간 불변 TDT
```
final_panel_data.csv에서:
모든 BUIDL 관측치: tdt_score = 62.5 (180일 동일)
모든 USDC 관측치: tdt_score = 87.5 (180일 동일)
```
**문제점**:
- 패널 데이터의 장점(시간 변동성 활용) 상실
- 자산 고정효과(Asset Fixed Effect)와 TDT가 완전 상관
- α_i (자산 고정효과)를 넣으면 TDT 추정 불가

**권장 조치**:
- 고정효과 대신 클러스터 표준오차 사용 (symbol 기준)
- 또는 시간에 따라 TDT가 변하는 설계 필요 (공시 업데이트 이벤트)

#### 한계 4: BUIDL의 거래량 0 문제
```
BUIDL 모든 관측치: volume = 0, price = 1.0
→ daily_return = 0, volatility = 0, illiquidity = NaN
```
**문제점**:
- 기관 투자 전용 토큰으로 공개 거래소에서 거래 안 됨
- Illiquidity 계산 시 분모가 0 → NaN
- 이런 관측치가 분석에 포함되면 bias 발생

**권장 조치**:
- 거래량 0인 관측치 제외
- 또는 BUIDL 같은 기관 전용 토큰은 별도 분석

## Part 2: 논문 심사위원 관점의 비평

### 📋 Reviewer 1 (방법론 전문가)

> **Major Concern 1: TDT 측정의 타당성(Validity)**
>
> "논문은 TDT 점수가 '투명성'을 측정한다고 주장하나, 측정 도구의 타당성 검증이 부족합니다.
> - **내용 타당성(Content Validity)**: 8개 필수 필드가 왜 '투명성'의 완전한 정의인가?
> - **수렴 타당성(Convergent Validity)**: 다른 투명성 지표(예: 규제 등급)와 상관관계는?
> - **예측 타당성(Predictive Validity)**: TDT가 실제 투자 의사결정에 사용되는 증거는?
>
> 최소한 전문가 패널 검토나 기존 지표와의 비교가 필요합니다."

**대응 방안**:
- Limitation 섹션에 측정 타당성 한계 명시
- 후속 연구로 전문가 델파이 조사 제안

---

> **Major Concern 2: 내생성(Endogeneity) 문제**
>
> "TDT → 변동성 관계에서 역인과(reverse causality) 가능성이 있습니다.
> - 가설: 투명성이 좋아서 변동성이 낮다
> - 대안: 변동성이 낮은(안정적인) 프로젝트가 공시를 더 잘 할 여력이 있다
>
> 도구변수(IV)나 준실험 설계 없이 인과관계 주장이 어렵습니다."

**대응 방안**:
- 인과관계가 아닌 상관관계로 해석 톤 완화
- "공시 업데이트 이벤트" 전후 분석으로 인과성 강화 시도

---

> **Minor Concern: 통계적 다중성(Multiple Testing)**
>
> "H1, H2, H3, RQ3 총 4개 모델에서 다수의 계수를 검정하고 있습니다.
> Bonferroni 보정이나 FDR 조정이 필요합니다.
> H1의 p=0.05는 보정 후 유의하지 않을 수 있습니다."

**대응 방안**:
- Bonferroni 보정 적용: α = 0.05 / 4 = 0.0125
- 보정 후에도 유의한 결과만 강조

---

### 👨‍🏫 지도교수 관점의 비평

> **전체 평가: B+ (조건부 통과)**
>
> "프레임워크 설계와 데이터 파이프라인은 훌륭합니다. 특히 순환 논리 문제를 인식하고 스스로 수정한 점이 좋습니다. 하지만 몇 가지 보완이 필요합니다:
>
> **1. 솔직함(Honesty)**
> H2가 가설과 반대 방향으로 나온 것은 문제가 아닙니다. 오히려 정직하게 보고하고 이유를 논의하면 좋은 논문이 됩니다. 'Null 결과도 결과'입니다.
>
> **2. 스토리라인 조정**
> 원래 가설: TDT ↑ → 모든 리스크 ↓
> 수정 제안: TDT의 'consistency' 요소가 핵심. 전체 점수보다 구성요소별 효과가 다름.
>
> **3. 논문 기여 재정의**
> - 이론적 기여: TDT 프레임워크 제안 (3-layer 구조)
> - 실증적 기여: consistency가 핵심 요소임을 발견
> - 실무적 기여: 거래소/VC용 리스크 모니터링 도구
>
> **4. 표본 정제**
> 현재 22개 토큰 중 정보 없는 13개를 제외하고 9개로 분석해도 됩니다. 표본이 작아져도 질이 높아지면 괜찮습니다."
