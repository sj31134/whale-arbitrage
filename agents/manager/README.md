# 투자 매니저

[로컬 작업 원장](WORK.md)에 접수한 지시의 대상 분야와 기준시각을 정한다. 각 분야는 자기 폴더의 지침과 배정된 원천을 검토해 결론, 근거, 하방 위험, 재검토 조건을 게시한다. 매니저는 참여한 분야의 보고서를 대조해 같은 원문을 중복 집계하지 않고 합의점, 충돌, 미확인 변수를 기록한다. 투자 결정과 주문 권한은 사용자에게 있다.

담당 보고서를 먼저 게시한 뒤 그 ID들을 매니저 보고서의 `inputs`로 전달한다. 사용자는 매니저 화면에서 종합 판단이 인용한 당시 보고서로 이동할 수 있다. 상세 입력 형식과 실행 명령은 [분석 결과 게시](../../private_accounts/README.md#분석-결과-게시)를 따른다.

## 현재 연구 우선순위

일일 신규 수집·갱신과 아침 브리핑은 국내·해외 주식과 토큰화 주식에 우선순위를 둔다. 해외 파이프라인은 미국부터 검증한다. 매니저 화면과 종목별 검토의 범위는 전체 포트폴리오이며, 다섯 담당과 열 개 데이터 범주, 기존 보고서와 관리 기능을 모두 제공한다. 개별 담당 요청과 수동 범주 갱신은 각 담당의 전체 범위를 따른다. 시장별 마지막 완료 거래일, KST 기준시각, 원문 발표시차와 자료 공백을 표시한다.

주식 담당은 발행기업의 현금흐름·희석·가격과 촉매를 평가한다. 토큰화 주식은 코인 담당이 발행사 약관, 증표 단위당 기초주식 수, 배당·분할 방식, 환매 자격·비용과 양방향 호가를 확인한다. 매니저는 두 결과를 기초주식 단위로 합쳐 기업 중복 노출을 점검하고, 발행사·수탁사 위험은 별도로 본다. 기초시장 마감 후의 괴리, 시세 결측, 환매 중단을 구분한다. 보유 대조는 Mac 안에서만 수행한다.

기본 비교는 같은 기간·통화·배당 조건의 시장 총수익지수 및 기존 보유 유지안이다. 수수료·환전·호가차·슬리피지를 반영하고 세금은 확인된 계좌 규칙을 적용한다. 발표 당시 알 수 있던 정보로 검증한 비용 차감 초과수익과 최대낙폭을 함께 보고한다. 매일 아침에는 가설을 바꾼 변화, 다음 촉매, 반증 조건을 우선 표시한다.

## 이전 채팅형 대시보드 모의 사용 기록

2026년 11월 23일에 여섯 역할이 임시 계좌 저장소와 모의 관측 자료로 분석실을 점검했다. 분야마다 기준일이 다른 관측값 두 개를 입력하고 해당 역할의 질문을 보냈다. 매니저는 고래와 코인만 선택해 같은 원문을 쓰는 경우를 검토했다. 로컬 Qwen2.5 3B 한 개가 각 분석실의 답변을 생성한 뒤 렌더링된 메뉴와 일부 자료 행·근거 행을 읽고 개선 의견을 작성했다. 점검 시 모델 응답 길이는 회당 최대 270토큰으로 설정했다. 웹 요청과 HTML 응답을 점검했으며 실계좌 수치와 실제 사람의 평가는 사용하지 않았다.

매니저 화면의 **대시보드 개선 의견 → 페르소나 모의 사용 점검 결과**에 여섯 의견의 요지와 반영 내용을 모았다. 같은 화면에서 이후 사용자가 등록한 의견의 처리 상태를 관리할 수 있다. [점검 기록](DASHBOARD_REVIEW.csv) · [페르소나 정의](../personas.py)

미국 소형주 재점검에서 모델 문장이 모의 시총 자료의 기준일을 놓쳤다. 화면은 질문 당시 등록한 시총·베타의 기준일과 분류 보류 사유를 코드로 계산해 답변 위에 보관한다. 사용자는 나중에 변수를 수정해도 당시 근거를 다시 대조할 수 있다.

개선 후에는 고정 답변을 쓰는 테스트 모델로 여섯 화면의 질문 제출과 결과 조회를 다시 실행했다. 각 분석실에서 앞서 받은 의견을 임시 저장소에 한 건씩 등록하고 매니저 화면에서 여섯 건을 모두 확인한 뒤 반영 완료로 전환했다.

## 매일 변동 종목·섹터 검토

오전 8시 KST 브리핑은 국내·미국 마지막 완료 거래일, 토큰화 주식 호가 시각, 표본 범위를 기록한다. 가격 이상치를 찾은 뒤 종목 공시가 가격 변화에 앞섰는지, 시장·동종 업종의 공통 충격인지, 수급과 5거래일 지속성이 지지하는지 각각 확인한다. 다음 촉매, 비용·슬리피지를 반영한 연구 의견과 반증 조건을 남긴다. 거래소의 프로그램매매·시장조치는 원문 기준을 따르고 가격·거래량으로 추정한 원인과 구분한다. 게시 순서는 분야 보고서, 로컬 교차검증, 실제 분야 ID를 인용한 매니저 보고서다. 휴장, 미발표, 결측, 정정, 자동 수집 실패일에도 공개 시장 브리핑을 제출한다.
